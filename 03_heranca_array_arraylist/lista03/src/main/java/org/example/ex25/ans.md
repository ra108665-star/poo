a) No paradigma de programação orientada a objetos, a herança permite que uma
classe possa utilizar os mesmos atributos e métodos de outra classe.

b) A classe mãe não pode ser utilizada no `main`, porém fornece métodos e atribu 
tos para a filha/filhas.

c) Um array é uma estrutura de dados que armazena valores do mesmo tipo. Além di
sso é fixo, ou seja, não aumenta nem diminui.

d) Um `ArrayList` é uma estrutura de dados do Java, que funciona como uma lista
dinâmica.

e) O array tem tamanho fixo, em sua declaração. Já o `ArrayList` pode crescer ou 
diminuir de tamanho.

f) `Aluno` e `Professor` são subclasses de `Pessoa`. Isso representa o polimor-
fismo, onde uma referência do tipo da classe mãe pode armazenar objetos das clas
ses filhas.
