Um `array[]` é utilizado quando a quantidade de elementos é conhecida e, conse-
quentemente, o desempenho é melhor. As inserções e remoções são mais difíceis,
pois o tamanho é fixo.

Um `Arraylist<>` é utilizado quando o tamanho da lista é variável. Para adicio-
nar para adicionar `.add()` na variável. Ele é mais lento que um array.
